# 英语单词学习软件 · 产品功能规划（PRD v0.1）

> 本文档是**产品层面的规划**（做什么、为什么做、怎么分期）。
> **业务规则的唯一依据是 [`LOGIC_FLOW.md`](./LOGIC_FLOW.md)**；界面与组件约定见 [`UI_CONTRACT.md`](./UI_CONTRACT.md)。
> 第 7、8 章已按当前实现更新，其余章节保留最初的规划原文。

> 目标：一套代码同时覆盖 **手机端（iOS / Android）** 与 **电脑端（Windows / macOS / Linux / 浏览器）**，
> 核心是「记得住」而不是「背得多」——用间隔重复算法把复习安排在遗忘临界点。

## 3. 模块详细设计

### 3.1 词书与词库

**内置词书（开箱即用）**
- 学段：小学 / 初中 / 高中 / 大学四级 / 大学六级
- 考试：考研 / 雅思 / 托福 / GRE / SAT
- 教材：新概念 1-4、人教版同步、牛津 3000、朗文 2000
- 主题：商务英语 / 旅游口语 / 医疗 / 计算机 / 学术写作

**自定义词书**
- 从内置词书勾选单词 → 组合成「我的词书」
- 手动新增单词、批量粘贴导入
- 导入格式：CSV / Excel / TXT（每行一词）/ JSON
- 导出：CSV / JSON / Anki apkg（方便迁移）

**单词数据模型**
```jsonc
{
  "id": "w_000123",
  "word": "abandon",
  "phonetic": { "us": "/əˈbændən/", "uk": "/əˈbændən/" },
  "audio": { "us": "abandon_us.mp3", "uk": "abandon_uk.mp3" },
  "senses": [
    {
      "pos": "v.",                       // 词性
      "translation": "放弃；抛弃",
      "definition_en": "to leave somebody/something",
      "examples": [
        { "en": "He abandoned his car.", "zh": "他弃车而去。", "source": "Tatoeba" }
      ]
    }
  ],
  "forms": { "past": "abandoned", "ing": "abandoning", "third": "abandons" },
  "etymology": { "roots": ["ab-", "-band-"], "note": "band=禁令 → 交出控制权" },
  "collocations": ["abandon hope", "abandon ship"],
  "synonyms": ["desert", "forsake"],
  "antonyms": ["keep", "retain"],
  "tags": ["CET4", "high_freq"],
  "frequency_rank": 812
}
```

**学习状态模型（与词条分离，可多端同步）**
```jsonc
{
  "word_id": "w_000123",
  "book_id": "cet4",
  "state": "review",          // new | learning | review | relearning | mastered
  "stability": 12.4,          // FSRS：记忆稳定度（天）
  "difficulty": 6.2,          // FSRS：难度 1-10
  "due": "2025-10-08T00:00:00Z",
  "last_review": "2025-09-26T09:12:00Z",
  "reps": 5, "lapses": 1, "correct_streak": 3,
  "elapsed_ms": 3200,
  "wrong_count": 1,
  "updated_at": 1758870000      // 用于多端冲突解决（LWW）
}
```

### 3.2 学习引擎（核心竞争力）

**调度算法**
- 一期：SM-2 简化版（Anki 经典算法，好实现、可解释）
- 二期：升级 **FSRS-5**（Free Spaced Repetition Scheduler，开源、比 SM-2 少 20~30% 复习量）
- 三档反馈：`忘记 / 模糊 / 记得`（可选四档：完全忘记 / 困难 / 一般 / 简单）
- 掌握度 = f(稳定度, 正确率, 连续次数)，`stability ≥ 90 天` 标记为已掌握

**每日任务队列生成逻辑**
1. 取所有 `due <= 今天` 的复习卡（优先级：逾期越久越靠前、曾忘记过的加权）
2. 补充 `每日新词目标` 个新词（默认 20，可调）
3. 学习中的卡优先穿插复习
4. 总量封顶：`每日上限 = 新词目标 + 复习上限`（防止雪崩式积压）
5. 排队顺序：`混合`（推荐）/ `分组`（先复习后新词）/ `随机`

**自动降级（防挫败）**
- 连续 3 次回答错误 → 该词降回 learning，并在当日稍后再出现一次
- 单日错误率 > 60% → 弹窗建议降低新词数量

### 3.3 学习模式（多种交互形式）

| 模式 | 说明 | 适用 |
|---|---|---|
| 单词卡翻转 | 正面单词+发音，点击/空格翻面看释义，自评 | 主力模式 |
| 选择题 | 给单词选中文 / 给中文选单词（4 选 1，干扰项同词性同难度） | 快速过词 |
| 拼写填空 | 听音或看中文拼写，字母提示可开 | 强化输出 |
| 听写 | 只播音，不看文本 | 听力向 |
| 例句填空 | 从例句中挖掉目标词，语境记忆 | 深度记忆 |
| 词根词缀 | 按词根家族成组学习（spect = 看：inspect / respect / suspect） | 拓展词量 |
| 浏览模式 | 快速滑动浏览词表，不参与调度 | 预习 |

**通用交互能力**
- 快捷键（桌面）：`空格` 翻面、`1/2/3` 评分、`←` 上一张、`S` 发音、`P` 收藏
- 手势（手机）：左右滑切换、上滑标记已掌握、下滑加入生词本
- 自动发音、跟随模式（完全不点，自动播报+自动下一张）
- 深色模式、字号调节、生词自动加入生词本

### 3.4 复习与测验

- **到期复习**：首页显示 `今日待复习 42 / 新词 20`
- **错题本**：自动收集答错的词，可单独「只练错词」
- **收藏/生词本**：手动标记，跨词书共享
- **阶段性测试**：从已学词中随机抽 30 题，生成正确率报告，记录历史趋势
- **拼写挑战赛**：限时 3 分钟，看能连对多少（游戏化复习）

### 3.5 发音与听力

- 单词/例句发音：优先本地音频库（离线可用），缺失时回退浏览器 TTS / 系统 TTS
- 英美双音切换，语速 0.5x ~ 1.5x
- 跟读打分（二期）：录音 → 提取特征 → 与标准音频比对给出评分（可用 Web Speech API 或云端 ASR）

### 3.6 数据与统计

- **打卡日历热力图**（GitHub 风格，按学习量着色）
- 核心指标：今日学习数 / 连续天数 / 累计词量 / 已掌握 / 平均正确率 / 总时长
- **记忆曲线**：已学词按稳定度分桶（<1天 / 1-7天 / 7-30天 / >30天）
- **预测**：按当前进度预测「完成词书还需 N 天」「考试日预计掌握率 X%」
- **学习报告**：周报 / 月报，可导出图片分享
- 单词语料统计：最常忘的 20 个词（附一键专项复习）

### 3.7 游戏化（轻量，不做重社交）

- 连续打卡天数（streak）+ 断签保护卡（每月 N 张）
- 经验值 / 等级 / 每日目标完成动画
- 成就徽章：首次满勤、累计 1000 词、单日 200 词、零错误通关、连续 30 天
- 可选：好友榜 / 学习小组（三期，需服务端）

### 3.8 个性化

- 每日目标：新词数（5~100）、复习上限、每日时长目标
- 提醒：多时间段推送（早/午/晚），支持「错过提醒补发」
- 学习偏好：显示中/英/双语、是否自动发音、是否强制拼写
- 主题：浅色 / 深色 / 跟随系统 / 护眼绿 / 主题色自选
- 无障碍：字号缩放、高对比度、屏幕阅读器标签

### 3.9 系统能力

- **离线优先**：所有学习行为本地落库（IndexedDB / SQLite），无网可完整使用
- **账号与同步**：邮箱 / 第三方登录；同步学习记录、自定义词书、设置
- **冲突解决**：按 `updated_at` 后写覆盖；词书内容冲突保留两份
- **多端适配**：
  - 手机：底部导航（今日 / 词书 / 统计 / 我的），大按钮、滑动手势
  - 桌面：左侧栏 + 主区 + 右侧详情/快捷键面板，键盘操作、批量管理
  - 平板：双栏布局
- **数据导出**：全量 JSON 备份、CSV 词表导出
- **隐私**：学习数据默认仅存本地，同步可选开启

## 4. 技术方案（建议）

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | **React 19 + TypeScript + Vite** | 一套代码覆盖 Web / 桌面 / 移动 |
| UI | Tailwind CSS + 自研组件 / shadcn-ui | 响应式断点天然支持手机+电脑 |
| 状态 | Zustand（轻量） + TanStack Query | 本地优先、易调试 |
| 本地库 | IndexedDB（Dexie.js，Web）/ SQLite（Capacitor 原生） | 离线存储万级词条 + 学习记录 |
| 桌面壳 | **Tauri 2**（首选，包体 ~5MB）/ Electron（备选） | 跨平台 Win/mac/Linux |
| 移动壳 | **Capacitor 7**（复用同一 Web 构建产物） | 复用度最高，能调原生 API |
| 发音 | 本地 mp3 音频包 + Web Speech API 兜底 | 离线可用 |
| 后端 | 一期：**无后端**（纯本地）；二期：Node/Fastify + PostgreSQL + Prisma | 先跑通价值，再上云 |
| 同步 | 二期：REST + 增量推送 + LWW | 简单可靠 |
| 部署 | Web: 静态托管；桌面：签名安装包；移动：TestFlight / APK | |

> 备选方案：Flutter（一套代码 + 原生性能，但 Web 端体验偏弱、生态偏 UI）。
> 若你更看重「桌面端像原生 App」，可在确认阶段改选 Flutter。

### 落地现状（v2 重写后）

v1 的实现存在一批状态流转缺陷（切书可无限刷词、进度条会算成负数、复习无终止条件等），
已在 v2 中按 `LOGIC_FLOW.md` 整体重写数据层、会话逻辑与界面。当前状态：

| 项 | 规划 | 实际实现 |
|---|---|---|
| 样式方案 | Tailwind CSS | **手写 CSS + 设计令牌**（墨蓝/米白，零额外依赖，构建更快） |
| 调度算法 | 一期 SM-2 | **间隔表 + 到期过滤**（`src/lib/srs.ts`）：连续答对次数映射到 1/2/4/7/15/30/60/90 天，满 90 天毕业 |
| 今日任务 | 每日 0 点定时任务 | **启动时惰性补跑 + 按 `(day, kind, bookId)` 幂等**：纯前端无法保证 0 点真的执行，定时器只做兜底 |
| 词书 | 内置多本 | CET4 核心 653 词 + 雅思学术 30 词；支持自建词书与导入 |
| 复习池 | 全部学过的词 | **只取 `due ≤ 今天` 的到期词**，当天新学的词不会当天被抽到 |
| 云端 | 一期无后端 | ✅ 纯本地 IndexedDB，无任何网络请求 |
| 发音 | 系统 TTS | ✅ Web Speech API（不支持时按钮置灰并说明） |
| 图表 | Recharts | 未引入 —— 趋势柱/日历/分布条用 CSS 实现，包体更小 |

验证：`npx tsc --noEmit` 零错误；`npm test` **240 项**自动化测试全通过（逻辑 54 + 数据 124 + 端到端 62）；
`npm run build` 通过；开发服务器 `http://localhost:5273` 可访问。

## 8. 关键决策（已定）

| 决策 | 结论 |
|---|---|
| 技术栈 | React + TypeScript + Vite；打包桌面/移动端的事留到 M3 |
| 形态优先级 | 先做**浏览器即开即用**的 Web 版（已实现），再考虑 Tauri / Capacitor |
| 云端账号 | 一期纯本地；用 JSON 导出/导入解决换设备问题 |
| 发音方案 | 系统 TTS（免费、离线、音质一般但零体积） |
| 首批词书 | CET4 核心词 |
| 词库规模 | 精选高频词而非全量词库；词条结构支持后续替换为 ECDICT 等大词库 |

仍待决定（属于 M2 之后）：是否引入真人音频包、是否做多端同步、是否接入 FSRS-5。
